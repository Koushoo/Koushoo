# Profile artwork

The header uses a small terminal window, a neutral palette and a single muted green accent. The project directory lists the two tools described in the README. A small pixel cat sits beside it.

Only the prompt cursor moves. Reduced-motion preferences disable that animation. Light and dark versions follow the browser colour scheme. The SVG contains no JavaScript, external images or fonts.

Run `python scripts/build_profile_art.py` to regenerate the banners and static project icons. It needs only the Python standard library. The daily snapshot runner does not modify these files.
